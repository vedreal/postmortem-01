## The entry

One short account, one or two sentences and no more than 400 characters,
of the silliest or most fatal time an AI coding agent misunderstood what it
was asked or wrecked the code it was given. Ten fresh candidates are scored
against the judge's criteria in order — on-subject, funny, specific, tight
wording, stakes — and the winner is written to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

The chosen account is written to `/output/entry.txt` (one or two sentences,
at most 400 characters).
